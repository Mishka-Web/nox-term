# NOX Browser — руководство пользователя

NOX — минималистичный терминальный браузер на Rust. Он работает прямо в терминале и предназначен для быстрого просмотра сайтов, документации, API-ответов и текстового веб-контента.

> NOX — текстовый браузер. Он не запускает JavaScript и не рендерит CSS как Chrome/Firefox.

# Установка

## Windows

Если у тебя уже есть portable-версия:

```powershell
.\nox.exe
```

Чтобы запускать NOX из любой папки, добавь каталог с `nox.exe` в `PATH`.

После этого:

```powershell
nox
```

или сразу открыть сайт:

```powershell
nox github.com
```

---

## Linux

Сделай файл исполняемым:

```bash
chmod +x nox
```

Запусти:

```bash
./nox
```

Для глобального запуска:

```bash
sudo mv nox /usr/local/bin/nox
```

После этого:

```bash
nox
```

---

## macOS

Сделай файл исполняемым:

```bash
chmod +x nox
```

Перемести его в каталог из `PATH`:

```bash
sudo mv nox /usr/local/bin/nox
```

После этого:

```bash
nox
```

# Первый запуск

Просто запусти:

```bash
nox
```

Или передай адрес:

```bash
nox https://example.com
```

Протокол можно не указывать:

```bash
nox github.com
```

Если вместо URL написать обычный текст, NOX может использовать его как поисковый запрос:

```text
rust ratatui examples
```

# Вкладки

Создать новую вкладку:

```text
Ctrl+T
```

Закрыть текущую:

```text
Ctrl+W
```

Перейти на следующую:

```text
Ctrl+Tab
```

Быстрый переход по номеру:

```text
Alt+1
Alt+2
...
Alt+9
```

Каждая вкладка имеет собственные:

- текущий URL;
- историю Back/Forward;
- позицию прокрутки;
- поиск по странице;
- состояние страницы.

```text

```


# Ссылки

Нажми:

```text
Tab
```

Откроется список ссылок текущей страницы.

Навигация:

```text
j
k
```

или:

```text
↑
↓
```

Открыть выбранную ссылку:

```text
Enter
```

Скачать выбранную ссылку:

```text
d
```

Закрыть список:

```text
Esc
```

---

# История

Открыть глобальную историю:

```text
H
```

NOX сохраняет посещённые страницы между запусками.

История навигации внутри вкладки и глобальная история посещений — разные вещи.

---

# Закладки

Добавить текущую страницу в закладки:

```text
m
```

Если страница уже находится в закладках, повторное нажатие удалит её.

Открыть список закладок:

```text
M
```

---

# Reader Mode

Reader Mode убирает лишние элементы страницы и старается оставить основной текст.

Переключить:

```text
R
```

Полезно для:

- статей;
- документации;
- блогов;
- README;
- длинных текстовых страниц.

---

# Формы

NOX поддерживает базовые HTML-формы.

Открыть список форм:

```text
F
```

Поддерживаются:

- `text`;
- `password`;
- `textarea`;
- `checkbox`;
- `radio`;
- `select`;
- `submit`;
- GET-формы;
- POST `application/x-www-form-urlencoded`.

## Редактирование поля

Выбери поле:

```text
j / k
```

Нажми:

```text
Enter
```

Введи значение.

Подтверди:

```text
Enter
```

---

## Checkbox / Radio / Select

Обычно используется:

```text
Space
```

---

## Отправка формы

Выбери кнопку Submit и нажми:

```text
Enter
```

NOX соберёт значения формы и отправит запрос.

> Сложные JavaScript-формы могут не работать, потому что NOX не выполняет JavaScript.

# Загрузки

Чтобы скачать ссылку:

1. открой список ссылок:

```text
Tab
```

2. выбери нужную:

```text
j / k
```

3. нажми:

```text
d
```

Файлы сохраняются в каталог загрузок, указанный в конфигурации.

# JSON

Если сервер возвращает:

```text
Content-Type: application/json
```

NOX автоматически старается красиво отформатировать ответ.

Например:

```json
{
  "id": 1,
  "name": "Richer",
  "active": true
}
```

Это удобно для просмотра REST API прямо из терминала.

---

# Cookies

NOX поддерживает cookie-хранилище между запусками.

Очистить cookies:

```bash
nox cookies clear
```

Cookies используются для сайтов, которым нужны обычные HTTP-сессии.

> Сайты со сложной JavaScript-аутентификацией могут не работать.

# Конфигурация

Посмотреть путь к конфигурации:

```bash
nox config --path
```

Посмотреть путь ко всем данным NOX:

```bash
nox data --path
```

Пример `config.toml`:

```toml
homepage = "about:home"

search_engine = "https://html.duckduckgo.com/html/?q={query}"

restore_session = true

reader_mode = true

max_history = 1000

user_agent = "NOX/0.4 terminal-browser"

# download_dir = "D:/Downloads/NOX"
```

---

## `homepage`

Стартовая страница:

```toml
homepage = "https://example.com"
```

---

## `search_engine`

Шаблон поисковой системы:

```toml
search_engine = "https://html.duckduckgo.com/html/?q={query}"
```

`{query}` будет заменён на поисковый запрос.

---

## `restore_session`

Восстанавливать вкладки после перезапуска:

```toml
restore_session = true
```

Отключить:

```toml
restore_session = false
```

---

## `reader_mode`

Запускать Reader Mode по умолчанию:

```toml
reader_mode = true
```

---

## `max_history`

Максимальное количество записей истории:

```toml
max_history = 1000
```

---

## `user_agent`

Свой User-Agent:

```toml
user_agent = "NOX/0.4 terminal-browser"
```

---

## `download_dir`

Windows:

```toml
download_dir = "D:/Downloads/NOX"
```

Linux:

```toml
download_dir = "/home/user/Downloads/NOX"
```

---

# Сессии

NOX может сохранять состояние открытых вкладок.

Если включено:

```toml
restore_session = true
```

после повторного запуска NOX попробует восстановить прошлую сессию.

Состояние хранится отдельно от бинарника NOX.

# Dump mode

NOX можно использовать без интерактивного интерфейса.

```bash
nox --dump https://example.com
```

Вывод будет отправлен прямо в stdout.

Пример:

```bash
nox --dump example.com > page.txt
```

Linux/macOS:

```bash
nox --dump example.com | less
```

Можно использовать в shell-скриптах и через SSH.

# Обновление NOX

Посмотреть текущую версию:

```bash
nox --version
```

Проверить наличие обновления:

```bash
nox update --check
```

Установить обновление:

```bash
nox update
```

NOX:

1. определяет текущую ОС;
2. определяет архитектуру CPU;
3. находит подходящий release;
4. скачивает новый бинарник;
5. сверяет SHA-256;
6. заменяет текущий бинарник.

# Ограничения

NOX пока не является полноценной заменой Chrome/Firefox.

Не поддерживается полноценный браузерный JavaScript runtime.

Поэтому могут не работать:

- SPA-приложения;
- React/Vue/Angular сайты, которые полностью зависят от JS;
- OAuth-флоу со сложным JavaScript;
- CAPTCHA;
- WebSocket-интерфейсы;
- видео;
- canvas;
- WebGL;
- сложные динамические формы.

Для обычного HTML, документации, статей, API и серверной работы NOX подходит значительно лучше.
